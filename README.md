## 🕹️ 게임 설명  

**CROSS ROAD GAME**은 C언어로 제작한 콘솔 기반 길 건너기 게임입니다.
플레이어는 자동차를 피해 도로를 건너고, 코인을 획득하며 점수를 올릴 수 있습니다.
스테이지가 올라갈수록 자동차 수와 속도가 증가하여 난이도가 점점 높아집니다.

닌텐도 스위치 형태의 콘솔 UI를 적용하여 단순한 텍스트 게임이지만 시각적으로 게임기 화면처럼 보이도록 구성했습니다.

또한 후반 스테이지의 긴장감을 높이기 위해 **Rush Hour** 모드를 추가했습니다.
**Rush Hour** 모드에서는 자동차 수가 증가하고 이동 속도가 빨라져 플레이어가 더 신중하게 이동 타이밍을 판단해야 합니다.

## 📌 게임 규칙

- 플레이어는 아래쪽 시작 지점에서 출발합니다.
- 위쪽 목표 지점에 도착하면 스테이지를 클리어합니다.
- 자동차와 충돌하면 생명이 1 감소합니다.
- 생명이 모두 사라지면 게임 오버가 됩니다.
- 코인을 획득하면 점수가 증가합니다.
- 스테이지가 올라갈수록 자동차 수가 증가하고 속도가 빨라집니다.
- 3스테이지부터 Rush Hour 모드가 발생합니다.
- Rush Hour 모드에서는 자동차 수가 증가하고 이동 속도가 빨라집니다.
- 최고 점수는 bestscore.txt 파일에 저장됩니다.

## 🚦 Rush Hour 모드

Rush Hour 모드는 실제 도로의 혼잡 시간대를 게임에 적용한 기능입니다.
기존에는 스테이지가 올라갈수록 자동차 수와 속도만 증가했지만, Rush Hour 모드를 추가하여 후반 스테이지에서 순간적인 긴장감을 높였습니다.

Rush Hour 모드가 발생하면 화면 상단에 다음과 같은 문구가 표시됩니다.

!!! RUSH HOUR MODE !!!        CARS +3 / SPEED x2

Rush Hour 모드에서는 자동차가 추가로 등장하고, 자동차 이동 속도도 빨라집니다.

### 스테이지 Rush Hour 발생 횟수
Stage 1	없음  
Stage 2	없음  
Stage 3	1번  
Stage 4	2번  
Stage 5	3번

## 🧱 주요 구조체

플레이어의 위치, 생명, 점수, 현재 스테이지, 닉네임을 저장합니다.

typedef struct {
    int x;
    int y;
    int life;
    int score;
    int stage;
    char name[NAME_MAX];
} Player;
Car

자동차의 위치와 이동 방향을 저장합니다.

typedef struct {
    int x;
    int y;
    int dir;
} Car;
Coin

코인의 위치를 저장합니다.

typedef struct {
    int x;
    int y;
} Coin;

## ⚙️ 실행 방법

### 1. 컴파일

```bash
gcc main.c -o game.exe
```

### 2. 실행

```bash
./game.exe
```

```bash

```

또는 PowerShell에서는 다음과 같이 실행합니다.

